# תיקון תצוגת תזכורות — 6.10.2026

התיקון עלה ונבדק בארבעת אתרי הלקוחות: מלמד, מור לוי, אשרף עיסא ו־IDM, אחרי בדיקה בסביבת Melamedia.

## השינויים

- הנמענים וערוצי השליחה מוצגים כשדות נפרדים, עם ריווח ויישור לימין.
- הודעת הדחייה לשעות הפעילות והתאריך נמצאים באזור נפרד; התאריך שומר על סדר ספרות משמאל לימין.
- כפתור פתיחת האירוע ביומן מציג את כל הכיתוב. הוא וכפתור הסגירה מיושרים, ובמסך צר הכפתורים נערמים.
- שמות של כמה נמענים יכולים לרדת שורה. במובייל השמות מוצגים מעל התאריך והסטטוס, בלי חפיפה. בדסקטופ כותרות הטבלה ותאיה חולקים את אותם רוחבי העמודות.

## אימות

בניות הייצור של QA ושל ארבעת הלקוחות עברו. המיתוג, הסמלים וכתובות ה־API נבדקו מול כל לקוח בנפרד. נבדקו רכיבי React האמיתיים בדפדפן עם נתונים סינתטיים: חלונית רגילה, שלושה ערוצים, הודעת דחייה והיעדרה, כפתור היומן והסגירה, רשימת כמה שמות ושם ארוך, כולל רוחב 320 פיקסלים. כלי הבדיקה שמור בתיקיית ui-harness; גם הבנייה שלו נבדקה.

ב־QA החי נבדקה פתיחה וסגירה של תזכורת הדמו הקיימת, והגרסה הנטענת אומתה. תרחישי היומן וריבוי הנמענים נבדקו במתקן הרכיבים הסינתטי; לא נוצרו עבורם רשומות חדשות בשרת. לא נשלחו הודעות ולא שונו מועדי שליחה.

לאחר כל פריסה הושוו כל קובצי הבנייה על השרת לבנייה המקומית: מלמד 234, מור לוי 234, אשרף 236, IDM 232, QA 237. בנוסף, דרך כל דומיין ציבורי אומתו HTML, קובצי הכניסה ו־CSS/JavaScript של התזכורות, וכן בריאות API, הגדרות ציבוריות וחסימת ניהול חתימות ללא אימות. ב־HTML של אתרי ה־VPS הוסרה בהשוואה רק תוספת המדידה המדויקת של Cloudflare. אלו אינן בדיקות חדשות של כל תהליכי המוצר או של גרסאות החנויות.

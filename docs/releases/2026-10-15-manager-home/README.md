# מסך הבית למנהלים - מדריך ומימוש

עדכון 16 באוקטובר: [תיקוני היומן, ניקוד היסטורי לאוקטובר וניסוח התובנות](../2026-10-16-manager-home-fixes.md) מחליפים את ההנחיות הקודמות בנושאים אלה, וכוללים הוראות שימוש ותיעוד הפריסה.

הגרסה מעדכנת את דף הבית: היומן מופיע ראשון, היועץ העסקי מצביע על מוקדים מדודים לטיפול, ודירוג הצוות זמין להיום, לשבוע ולחודש. תצוגת התיקים לפי מנהל ותפעול החתימות משמרת את הפעולות הקיימות.

הפריסה כוללת את MelamedLaw, MorLevi, AshrafEssa ו-Idm, לאחר בדיקה ב-Melamedia. סביבת LawyerPlatform המשותפת והאפליקציות הנייטיב אינן מוחלפות במיזוג גורף של main. אין הפעלה אוטומטית של חיבורי WhatsApp או נט המשפט ואין משלוח הודעות בדיקה אמיתיות.

אומת שקוד המוצר כולל את איחוד המקבוק מ-15 באוקטובר ואת השינויים שנוספו אחריו. תמונת המקבוק העדכנית לא כללה שינוי חדש שנשמט. ענפי checkpoints היסטוריים נשמרים ולא מחליפים את קוד המוצר הפעיל.

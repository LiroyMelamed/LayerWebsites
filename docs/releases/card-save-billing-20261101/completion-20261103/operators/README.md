# Historical execution artifacts

These are exact operational source artifacts and narrowly scoped test fixtures from the 3 November release, retained for audit. They are **not general-purpose deploy commands**. Their original dependency paths, process identities, immutable configuration hashes, candidate bundles, observations, locks and single-use evidence directories belonged to this completed execution. Private source/configuration/backup material is intentionally not included here.

Do not run these files against a later live process or reuse a consumed receipt. A future release must derive a fresh baseline, preserve the appropriate configuration and use its own reviewed package. File hashes in `../evidence-manifest.json` establish what was retained; passing old test receipts does not authorize a new execution or make old runtime identities current.

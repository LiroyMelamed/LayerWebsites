[חבילת האישור ל־QA בלבד](../qa-isolation-approval/README.md) מפרטת8 דגלי pause+תגGIT_SHA לתהליךmelamedia-api בלבד, guard ותנאי תחילה, smoke ללא מזהי לקוח/הזמנה, revert שאינו מפעיל קוד ישן ללא fence, והשפעה על משתמשיQA/workers. זהו שלב בדיקות חסימה וקריאה בלבד; **אינו בידוד לבדיקה חיובית של גביית חוב**. אין להחיל config בזמן ששערי backup/restore/rollback/drain פתוחים. ל־schema-only דרך זהות הגיבוי הקיימת יש חוזה read-only נפרד; app-role נכשל ולא הוחלף אוטומטית.
